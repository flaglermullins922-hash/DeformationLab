# 全局变形教程：锥化 / 扭曲 / 弯曲 / FFD

> 配套 DeformationLab 工程阅读。目标是**从零理解**这四种网格变形在数学上到底做了什么。

---

## 0. 先分清两个概念

- **局部变形（Local Deformation）**：只改一小块顶点，影响范围有限。比如捏泥人只动一根手指。
- **全局变形（Global Deformation）**：用一个"规则"作用在**所有**顶点上，每个顶点根据它**在模型里的位置**得到不同的变换。锥化、扭曲、弯曲都属于这一类——它们不关心顶点是谁，只关心顶点"在哪"。

全局变形的统一套路：**先算一个归一化参数 t，再让变换量随 t 变化**。

---

## 1. 主轴与归一化参数 t

先给模型找一个"主轴"（默认 Y，即上下方向）。取包围盒 `[min, max]`，主轴高度 `H = max[axis] − min[axis]`。

对任意顶点 p，它在主轴上的**归一化位置**：

```
t = (p[axis] − min[axis]) / H        t ∈ [0,1]
```

- `t = 0` → 模型最底端
- `t = 1` → 模型最顶端

三种解析式变形，本质都是"变换量 = 某个函数 f(t)"。

---

## 2. 锥化 Taper

**目标**：让模型一头粗一头细（像个锥子）。

**做法**：在垂直于主轴的平面内做缩放，缩放系数随高度线性变化：

```
s(t) = 1 + k·t
```

- `k > 0`：顶部放大（上粗下细）
- `k < 0`：顶部收窄（上尖下宽）
- `k = 0`：不变

对垂直主轴的每个坐标 c（主轴不缩放）：

```
p'[c] = center[c] + (p[c] − center[c]) · s(t)
```

其中 `center` 是包围盒中心（缩放围绕中心线进行，保证模型不漂移）。

> 直观理解：想象把一根竖直的橡皮泥柱，在每一层高度上按"越往上缩得越多"的比例去挤/拉，就得到锥化。

---

## 3. 扭曲 Twist

**目标**：让模型像拧麻花一样绕主轴扭转。

**做法**：绕主轴旋转，旋转角随高度线性累计：

```
θ(t) = angle · t
p' = center + R(axis, θ(t)) · (p − center)
```

- `t = 0`（底部）：`θ = 0`，不转
- `t = 1`（顶部）：`θ = angle`，转满整个角度

绕 Y 轴的旋转矩阵：

```
x' = x·cosθ + z·sinθ
y' = y
z' = −x·sinθ + z·cosθ
```

> 直观理解：抓住模型上下两端，反方向一拧。每一层高度转的角度不一样，越往上拧得越狠。

---

## 4. 弯曲 Bend

**目标**：把"直的"模型弯成"弧形"。

**做法**：把直线主轴映射到圆弧上。这是三种里最绕的一个，一步一步来。

设弯曲角 `θ`（弧度），主轴高度 `H`，弯曲半径：

```
R = H / θ        （弧长 H 对应圆心角 θ）
```

取弯曲中心在主轴的 y 坐标 `yc`。对每个顶点，先算它相对弯曲中心的**弧长**：

```
s = p[axis] − yc
```

该顶点在圆弧上的**角度位置**：

```
φ = s / R
```

再算顶点在弯曲方向上、相对中心线的**偏移**：

```
off = p[bendDir] − cDir        （cDir 是弯曲方向上的中心）
```

弯曲后的两个坐标：

```
new(bendDir) = R·(1 − cosφ) + off·cosφ
new(axis)    = yc + R·sinφ − off·sinφ
```

**验证几个直觉：**

1. **在中心线上的顶点（off = 0）**：
   ```
   new(bendDir) = R(1−cosφ)，new(axis) = yc + R·sinφ
   ```
   这正是标准圆弧的参数方程（圆心在弯曲内侧、半径 R）。✓

2. **θ → 0**（几乎不弯）：`R → ∞`，`sinφ ≈ φ`，`cosφ ≈ 1`，代入后 `new(bendDir) ≈ off·1 + R(1−1) = off`，`new(axis) ≈ yc + R·(s/R) − 0 = yc + s = p[axis]`，即**不变**。✓

3. **弯曲方向**：`θ > 0` 往 +bendDir 弯，`θ < 0` 往 −bendDir 弯（R 带符号）。✓

> 直观理解：把一根直的软管贴到一个半径为 R 的圆筒外壁上，管子就弯成了弧形。

## 5. FFD 自由变形（Free-Form Deformation）

前面三种是"解析式"——变形规则是写死的公式。FFD 则是"格子驱动"的通用变形，Sederberg & Parry 1986 年提出，是自由变形（FFD）的开山之作。

### 5.1 思想：把模型"装进"一个格子

1. 算模型包围盒；
2. 在包围盒上均匀摆 `n×n×n` 个**控制点**（默认 n=4，即每边 4 个，共 64 个）；
3. 模型顶点"嵌入"到格子里，记下它在格子里的**参数坐标 (s,t,u)**；
4. 之后**只动控制点**，顶点通过 Bernstein 权重自动跟随。

### 5.2 初始状态：均匀格子

```
P[i,j,k] = min + (i/(n−1))·dx + (j/(n−1))·dy + (k/(n−1))·dz
```

其中 `dx/dy/dz` 是包围盒三个方向的尺寸，`i,j,k ∈ [0, n−1]`。这是作业要求的"**初始状态：通过计算模型包围框，得到 n×n×n 的网格点坐标**"。

### 5.3 嵌入：顶点 → 参数坐标

初始格子是均匀的，所以参数坐标就是简单的**线性归一化**：

```
s = (v.x − min.x) / dx
t = (v.y − min.y) / dy
u = (v.z − min.z) / dz
```

这一步之后，(s,t,u) **固定不变**——顶点"粘"在了参数空间里。

### 5.4 变形：Bernstein 张量积

移动控制点后，顶点新位置：

```
v' = Σᵢ Σⱼ Σₖ Bᵢ(s)·Bⱼ(t)·Bₖ(u) · P[i,j,k]
```

其中 Bernstein 基函数（m = n−1 次）：

```
Bᵢ(u) = C(m,i) · uⁱ · (1−u)^(m−i)
```

- `n=2`：线性（等价三线性插值）
- `n=3`：二次
- `n=4`：三次（最经典，默认）

这就是作业要求的"**终止状态：通过修改网格点坐标，观察模型变化**"。

### 5.5 为什么 Bernstein 张量积能"黏住"顶点？

关键性质：**Bernstein 基构成单位分解**，`Σᵢ Bᵢ(u) = 1`（对任意 u）。所以：

- 控制点不动时，`v' = v`（恒等，数学自检里专门验证了这一点）；
- 只动一个角点 `P[3,3,3]` 时，顶点移动量 = `B₃(s)·B₃(t)·B₃(u)` 乘以该角点的位移——**离角点越近的顶点动得越多，越远动得越少**，平滑过渡。

这正是 FFD 的优雅之处：**变形由"格子"决定，模型只是被动跟随**。想捏出任意形状，不用改公式，只要拖格子。

---

## 6. 一张图总结

| 变形 | 变换量随 t 的变化 | 关键参数 | 一句话 |
|---|---|---|---|
| 锥化 | 缩放 `s = 1 + k·t` | 系数 k | 一头粗一头细 |
| 扭曲 | 旋转 `θ = angle·t` | 角度 | 拧麻花 |
| 弯曲 | 弧角 `φ = s/R` | 角度、中心 | 掰弯软管 |
| FFD | Bernstein 张量积 | 控制点位置 | 拖格子捏形状 |

前三种是"写死公式"的解析变形，FFD 是"格子驱动"的自由变形——理解了这两类的区别，就理解了这一章的核心。
